# 🌾 AgriSense AI

AgriSense AI is an intelligent agriculture decision-support system for farmers and agriculture officers.  
It provides AI-based crop recommendations using soil, pH, water availability, and location.  
The system analyzes market prices, weather risks, crop diseases, irrigation, fertilizer, and crop demand.  
It also identifies government schemes and prioritizes high-risk villages for officer action.  
Built using **Python, Streamlit, Pandas, and CSV datasets**.
